# User Inyerface 

## Project Overview
This project focuses on manual testing of the User Inyerface web application to evaluate its functionality, usability, and user interactions.

## Testing Activities
- Functional Testing
- UI Testing
- Exploratory Testing
- Positive and Negative Testing
- Test Case Design and Execution
- Bug Identification and Reporting
